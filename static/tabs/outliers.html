Outlier Analysis

Statistical outliers via Z-score analysis · Peers = all active hospitals with data for the month
Column explanations
Value — the facility's actual reported indicator value for the month (e.g., C-section rate %).
Benchmark — the reference/peer average the value is compared against.
Peers — every other active hospital that has data for the same month, regardless of type or governorate. The hospital itself is excluded.
Z-Score — how many standard deviations the value sits from the benchmark mean. |z| ≥ 2 = unusual, |z| ≥ 3 = severe outlier.
Mode: Z-Score
