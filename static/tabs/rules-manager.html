compareCompares two sides with an operator. Each side is one indicator (read as-is) or a list (summed). factor scales the left side, for a factored bound. One comparison policy applies to every operator: tolerance is the rules policy's eq_tolerance; a side with no value passes; 0 compared with 0 passes. Example params: {"left":{"codes":["2"],"agg":"single"},"right":{"codes":["3","4","5"],"agg":"sum"},"op":">="}. Legacy comparison types (ge, gt, eq, ge_factor, le, lt, le_sum, parent_le, parent_lt) still evaluate as aliases, and an old rule opens in this builder as its compare equivalent.left, right (each {codes[], agg}), op (=, !=, >, >=, <, <=), optional factor{"left":{"codes":["2"],"agg":"single"},"right":{"codes":["6.d","6.e"],"agg":"sum"},"op":"=","factor":1.1}
